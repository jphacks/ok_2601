## 製品概要
### 背景(製品開発のきっかけ、課題等）
    「健康のために筋トレを始めたいけど、全然興味ないしやる気でない...」そんな悩みを解決すべく、IT（インテリトレーニー）が筋トレ「超」入門アプリをつくりました！
### 製品説明（具体的な製品の説明）
    「部位別トレーニングの記録」「カレンダーによる振り返り」等、筋トレ管理アプリの標準機能を搭載。独自機能として、トレーニングの回数に合わせて3Dアバターを変化させます。さらに、トレーニングによってゲットした「筋トレポイント」は一定数貯めるとガチャを引くことができ、アバターのスキンなどのアイテムを獲得することができます。
### 特長
#### 1. 特長1:３Dアバター
    トレーニング回数の記録に応じ、3Dアバターが成長していきます。これによりユーザのモチベーションを向上させる効果が期待されます。
#### 2. 特長2:モーションセンサーによる筋トレの検知
    iPhoneに標準搭載のモーションセンサーによって腹筋の起き上がりを検知します。
#### 3. 特長3:ガチャ
    筋トレの報酬は自分の肉体だけ...という考えは過去の物になりました。このアプリではトレーニングによって獲得できる「筋トレポイント」を用いてガチャを引くことができます。ただし、10回ごとにコストが上昇するため、より追い込みが必要になります。

### 解決出来ること
    筋トレ初期のモチベーションが出づらい時期に寄り添い、本格的な筋トレへの入門、ひいては生涯健康な体づくりをサポートします！
### 今後の展望
    ちゃんとジムへ通っているかを監視するGPS機能を搭載するとともに、筋トレ継続へのボーナスを増加させることでより継続的なトレーニングをサポートする機能を実装予定です。
