## 製品概要
### 背景(製品開発のきっかけ、課題等）
    「健康のために筋トレを始めたいけど、全然興味ないしやる気でない...」そんな悩みを解決すべく、IT（インテリトレーニー）が筋トレ「超」入門アプリをつくりました！
### 製品説明（具体的な製品の説明）
    「部位別トレーニングの記録」「カレンダーによる振り返り」等、筋トレ管理アプリの標準機能を搭載。独自機能として、トレーニングの回数に合わせて3Dアバターを変化させます。さらに、トレーニングによってゲットした「筋トレポイント」は一定数貯めるとガチャを引くことができ、アバターのスキンなどのアイテムを獲得することができます。
### 特長
#### 1. 特長1:３Dアバター
    トレーニング回数の記録に応じ、3Dアバターが成長していきます。これによりユーザのモチベーションを向上させる効果が期待されます。
#### 2. 特長2:モーションセンサーによる筋トレの検知
    iPhoneに標準搭載のモーションセンサーによって腹筋の起き上がりを検知します。
#### 3. 特長3:ガチャ
    筋トレの報酬は自分の肉体だけ...という考えは過去の物になりました。このアプリではトレーニングによって獲得できる「筋トレポイント」を用いてガチャを引くことができます。ただし、10回ごとにコストが上昇するため、より追い込みが必要になります。

### 解決出来ること
    筋トレ初期のモチベーションが出づらい時期に寄り添い、本格的な筋トレへの入門、ひいては生涯健康な体づくりをサポートします！
### 今後の展望
    ちゃんとジムへ通っているかを監視するGPS機能を搭載するとともに、筋トレ継続へのボーナスを増加させることでより継続的なトレーニングをサポートする機能を実装予定です。
### 注力したこと（こだわり等）
* Blender/Unityを使用した3Dモデリングの実装
* モーションセンサーによるトレーニングの検知
* 本格的にしすぎない

## 開発技術
### 活用した技術
#### API・データ
* 外部API：使用なし
* WorkoutRecord：筋トレのメニュー，回数，セット数，重量，日付，対象部位などの記録データを管理
* WorkoutStore：筋トレ記録，ポイント，ガチャの回数，獲得アイテムなどのアプリ内データを管理
* OBJ・MTL形式の3Dモデルデータ：筋肉の基本モデルと部位ごとの成長モデルを表示

#### フレームワーク・ライブラリ・モジュール
* Swift / SwiftUI：iOSアプリの実装およびユーザーインターフェースの構築
* Core Motion：iPhoneのモーションセンサーを利用した腹筋運動の自動計測
* SceneKit：3D筋肉モデルの読み込み，表示，部位ごとの成長表現
* Charts：筋トレ記録の統計・グラフ表示
* Combine：ObservableObject と @Published を利用したアプリ内データの状態管理
* Foundation：日付や数値などの基本的なデータ処理

#### デバイス
* iPhone（iOS）：筋トレ記録，モーションセンサーによる運動計測，3Dモデルの表示
* Xcode：iOSアプリの開発・ビルド環境

### 独自技術
#### ハッカソンで開発した独自機能・技術
* モーションセンサーを利用した腹筋の自動計測
    Core Motionで取得した端末の姿勢情報から，起き上がりと元の姿勢への復帰を検出し，腹筋の回数を自動カウントする機能を実装。
    該当ファイル：WorkoutMotion.swift，WorkoutMotionView.swift

* 筋トレ記録とポイントシステムの連動

    筋トレの回数とセット数に応じてポイントを獲得し，ガチャに利用できる仕組みを実装。記録追加時のポイント計算に，記録日数・連続記録日数・ガチャアイテムによる倍率を組み合わせている。

    該当ファイル：WorkoutStore.swift

* 筋トレ実績に応じて成長する3D筋肉モデル

    筋トレ記録から部位ごとの累計回数を算出し，その回数に応じて成長度を計算する仕組みを実装。SceneKitの3Dモデル表示機能を利用して，腕・胸・肩・背中・腹筋・脚などの成長を視覚的に表現する。

    該当ファイル：EvolutionView.swift

    関連データ：WorkoutRecord.swift，WorkoutApp/Features/Evolution/ 内の3Dモデルデータ

* ポイントを利用したガチャシステム

    筋トレで獲得したポイントを消費してアイテムを獲得する仕組みを実装。累計ガチャ回数に応じた価格変動や，10連ガチャの割引にも対応。

    該当ファイル：GachaView.swift，WorkoutStore.swift
